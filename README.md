# Twenty Nights in Bayford

An entry in the Bayford Inn Annual Art Competition 2026.

A countdown calendar for the Bayford Inn, Bayford, Somerset. Twenty doors are cut into a photograph of the bar room. One door opens each night from 7 November to the Anniversary & Awards Night on 26 November, and behind each is a true piece of Bayford's history. The page also has a pub-quiz round built from the doors you've opened, and a notice board for the competition itself.

The doors unlock by UK date, so nothing needs updating by hand: the countdown changes on its own every day. A "Preview every door" switch lets judges see all twenty at once.

## Running it

It's a single static page (`index.html`) plus two photos in `img/`. Host it anywhere, for example GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
